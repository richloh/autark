You are building a static, file-routed mock frontend for an open-source AWS-like platform called "Autark." Use Astro for pages/layouts and partial hydration. Use Tailwind CSS with JIT via a minimal build step. Keep client-side JavaScript small, componentized, and only where necessary.

Stack and constraints

- Framework: Astro for static site generation, file-based routing, and partial hydration.
- Styling: Tailwind CSS with JIT (configured in the Astro build step). Keep customization minimal; stay close to Tailwind defaults.
- JavaScript: Prefer Astro Islands (client:load/idle/visible) for interactive components; use small, framework-free ES modules where possible.
- Data: Load a local JSON manifest (data.json) at build time and make it available to pages via Astro’s data pipeline. For client mutations, rehydrate and persist changes using localStorage. No backend.
- No React/Preact/Vue unless absolutely necessary. If islands are required, prefer lightweight, framework-free web components or plain modules.
- No external assets beyond Tailwind CDN for dev; production uses compiled Tailwind CSS from the build. No image or font CDNs unless provided by the user.
- Output: A static site (dist) with Astro-generated HTML, compiled Tailwind CSS, and minimal client JS. Keep it responsive and mobile-friendly.

High-level goals

- Deliver a polished UI echoing AWS/GCP/Azure patterns: left navigation sidebar + top bar with account and project selectors.
- Implement list views, create/edit wizards, detail pages, and preset configuration pages for all menu items.
- Simulate provisioning flows with step-by-step status and progress.
- Provide real-time pricing estimates on create/edit wizards using pricing in the manifest.
- Add filtering, search, tagging, and bulk actions where relevant.
- Ensure full responsiveness and accessibility.

Pricing and cost estimations

Compute and display real-time costs using manifest pricing and app.currency:

- VM monthly = vCPU*vCPUPerMonth + RAM_GB*ramGBPerMonth + systemDisk_GB*systemDiskGBPerMonth + sum(attached volumes using volume pricing) + public IPv4 count*publicIPv4PerMonth + GPUs*(gpuPerHour*24*30)
- DB monthly = vCPU*vCPUPerMonth + RAM_GB*ramGBPerMonth + storage_GB*storageGBPerMonth + backup_GB*backupGBPerMonth; multiply by haMultiplier if HA
- Kubernetes control plane monthly = controlPlaneSmallPerMonth + (HA ? controlPlaneHAAddOnPerMonth : 0); worker nodes billed like VMs
- Object storage = storageGB*rate + requestsPerMillion*rate + egressGB*rate
- Load balancer = hourly_rate*24*30 + dataProcessedGB*rate
